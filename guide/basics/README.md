# Lua Basics

This module covers the fundamental concepts of Lua programming. By the end of this module, you'll understand Lua's core features and be ready to start hardware programming.

## Module Overview

1. [What is Lua?](01-what-is-lua.md) - Introduction to the Lua programming language
2. [Your First Program](02-first-program.md) - Writing and running your first Lua script
3. [Basic Syntax](03-syntax.md) - Variables, data types, and basic operations
4. [Control Structures](04-control-structures.md) - if/else, loops, and program flow
5. [Functions](05-functions.md) - Writing reusable code with functions
6. [Tables](06-tables.md) - Lua's powerful data structure
7. [File I/O](07-file-io.md) - Reading and writing files

## Prerequisites

- No prior programming experience required
- A computer with Lua installed (see [Installation Guide](../setup/installation.md))
- A text editor or IDE

## Learning Goals

After completing this module, you will:
- Understand what Lua is and why it's great for hardware programming
- Be able to write, run, and debug basic Lua programs
- Know how to use variables, functions, and control structures
- Understand Lua's table data structure
- Be comfortable reading and writing files in Lua

## Estimated Time

3-5 hours total (30-45 minutes per lesson)
