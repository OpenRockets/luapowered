# LuaPowered - Comprehensive Lua Programming Guide

Welcome to **LuaPowered**, a comprehensive learning resource for Lua programming with a special focus on hardware programming and embedded systems. This repository provides everything you need to go from a complete beginner to an intermediate Lua programmer.

## 🚀 What You'll Learn

- **Lua Fundamentals**: Basic syntax, data types, control structures, and functions
- **Hardware Programming**: Using Lua for microcontrollers, IoT devices, and embedded systems
- **Practical Projects**: Hands-on examples from simple scripts to complex hardware control
- **Best Practices**: Clean code, debugging, and performance optimization
- **Real-world Applications**: GPIO control, sensor reading, motor control, and more

## 🚀 Quick Start

**Want to jump right in?** → **[QUICKSTART GUIDE](QUICKSTART.md)** ← 5-minute setup!

1. **New to Lua?** Start with our [Beginner's Guide](guide/basics/README.md)
2. **Want to control hardware?** Jump to [Hardware Programming](guide/hardware/README.md)
3. **Learn by doing?** Check out our [Demo Projects](guide/projects/README.md)
4. **Try a working example** → Run `lua5.4 demos/smart_led_controller.lua`
5. **Need setup help?** See our [Installation Guide](guide/setup/installation.md)

## 🛠 Supported Platforms

This guide covers Lua programming for:
- **Raspberry Pi** (Raspberry Pi OS)
- **Arduino** (ESP32/ESP8266 with Lua firmware)
- **Linux** (Ubuntu, Debian, etc.)
- **macOS** (with Homebrew)
- **Windows** (with WSL or native installation)
- **Embedded Linux** systems
- **OpenWrt** routers
